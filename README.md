# MotoStore

Proyecto académico desarrollado con HTML5 semántico y CSS Flexbox.

## Características

- Página de venta de motocicletas.
- Diseño responsive.
- Uso de HTML5 semántico.
- Formulario accesible.
- Uso de Flexbox.
- Validación con W3C y WAVE.

## Tecnologías

- HTML5
- CSS3
- Flexbox
- ARIA
